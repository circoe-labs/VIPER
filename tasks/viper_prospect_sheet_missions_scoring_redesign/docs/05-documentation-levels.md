# Documentation levels

- Prospect score meaning: **Level 2 required** — dedicated contract must explicitly state commercial-fit-only semantics and forbidden graph contribution.
- Fiche completeness state: **Level 2 required** — states, threshold/config mapping and explanation contract.
- Proximity score: **Level 2 required**, ideally **Level 3** if the existing graph-scoring handoff already provides reusable service/types/tests.
- Prospect-scoped mission presets: **Level 2 required** — mapping from preset to mission target/objective/category/skill.
- UI visual hierarchy: **Level 1/2** in `doc/features/prospect-editor.md` and design-system documentation.
