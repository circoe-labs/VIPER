# Handoff — Fiche prospect : notes, profil et scoring

Ce dossier transforme la discussion et les deux captures d'ecran en demande exploitable par un agent d'implementation.

## Objectif

Rendre la fiche contact plus lisible et plus utile pour la qualification commerciale et la redaction d'e-mails personnalises :

- afficher les notes comme des faits compacts et faciles a parcourir ;
- reduire l'effet "formulaire administratif" de l'onglet Profil ;
- rapprocher identite et coordonnees dans un resume plus dense ;
- remplacer la grande carte "Verification de l'emploi" par une carte de scoring prospect ;
- rendre le score explicable via un detail des contributions ;
- exposer notes + scoring au contexte utilise par l'agent de redaction des mails.

## Etat du design

Design maturity: les intentions UX, l'information a mettre en avant et les interactions principales sont definies, mais aucun rendu final pixel-perfect n'a ete valide. Les captures incluses sont des references de l'interface actuelle, pas des maquettes cibles. Faire une passe de finalisation UI avant le polish visuel final si necessaire.

## Point d'entree

Lire d'abord `tasks/TODO.md`, puis executer les taches dans l'ordre.

Le texte court a donner directement a un agent se trouve dans `AGENT_REQUEST.md`.
